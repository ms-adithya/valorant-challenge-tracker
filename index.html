UPDATES

Changelog

Patch notes, fixes and major feature updates for Valorant Challenge Tracker.

Current v10.2
v10.2 — Reports & keyboard navigationMajor update · PDF reports, data recovery & keyboard access⌄

Added

  • Completed challenges now download a formatted PDF report directly, replacing the printable window that pop-up blockers could stop and that produced a different document in every browser.
  • Report text stays selectable and searchable, long match histories paginate properly, and every page carries a footer with the challenge name and generation timestamp.
  • A restore panel now appears on the create-challenge screen whenever no challenge is open, so archived challenges and backup files can be recovered without first having an active challenge.
  • Alt + arrow keys move between fields in the match entry form, following the visual grid rather than DOM order. Plain arrow keys are unchanged and still step number inputs and move the caret.

Fixed & improved

  • Enter now selects the highlighted option in the map, result and rank comboboxes instead of moving the highlight one row further, so a keyboard user can finally commit their choice.
  • Home and End jump to the first and last option in the combobox dropdowns, which arrow keys alone left unreachable in long lists.
  • Escape now closes only the open dropdown instead of also dismissing the match entry modal behind it.
  • Importing a backup now states plainly that it replaces every challenge, match and archived challenge stored in this browser, and both import controls share one confirmation.
  • Collapsed Advanced options no longer occupy layout while hidden.
v10.1 — Stability & interface polishPatch · Match history, charts & reliability⌄

Fixed & improved

  • Fixed Match History rendering and Sort & Filter reliability, including safe option generation and clearer active-filter feedback.
  • Trend and RR charts now retain actual Match History IDs, preserve numeric gaps and expose the real match number in point tooltips.
  • Recent matches and current-rank derivation now follow actual match numbers rather than insertion order.
  • Missing optional metrics display as unavailable instead of fabricated zero averages, and local-save failures now surface an actionable notice.
  • Improved table scrolling, sticky headers, keyboard focus and responsive toolbar/filter behaviour.

Sub patch · Rank & RR progression reliability

  • Introduced a centralized challenge rank/RR progression engine.
  • Added normalized runtime rank states distinguishing Recorded, Safely Derived and Unavailable values.
  • Missing RR remains unavailable instead of being interpreted as 0.
  • RR progression is derived only when mathematically safe from authoritative recorded data.
  • Missing RR or rank information safely stops derivation instead of producing guessed progression.
  • Placement (Unranked → Ranked) remains independent of promotion and demotion events.
  • Recorded values always take precedence over derived values.
  • Rank progression automatically rebuilds after add, edit, delete, import, restore and renumber operations.
  • Derived progression is runtime-only and never persisted as authoritative user-entered data.
v10.0 — Challenge completion & reportingMajor update · Completion workflow & exports⌄

Added & improved

  • Completed challenges now expose a challenge-scoped report export without automatically downloading anything.
  • Completion reports include overall summary, detailed analytics and optional full match history, with CSV and JSON data exports plus a printable report that can be saved as PDF.
  • Reports remain tied to the completed challenge even after another challenge is opened or created.
  • Unavailable optional statistics render as — instead of fabricated zero values.
v9.8 — Dynamic analytics overhaulMajor update · Analytics⌄

Improved

  • Added Analytics View ranges for All matches, Last 5, Last 10 and Last 20.
  • The selected analytics range now updates summary metrics, Shot Accuracy, Role Performance, Top Agents, Top Maps, Agent Usage, Map Rotation, and win-rate breakdowns together.
  • Shot Accuracy charts now use actual Match History IDs instead of artificial sequential positions.
  • ADR, ACS and DDΔ summary values are calculated from the active analytics range.
  • Agent usage ordering and analytics meters are now derived consistently from the underlying match data.
v9.6 — Match data integrity patchPatch · Data integrity & analytics⌄

Fixed

  • Optional RR After and RR Change values remain truly optional and are no longer converted into fabricated zero or null displays.
  • RR-dependent cards, recent-match displays and progression analytics correctly handle unavailable RR data.
  • Manual saves preserve blank Advanced Options, while legacy null-like stored values are normalised safely on load.
  • Match IDs remain stable after deletion and new matches use the lowest available positive match number.
v9.1 — Match import & entry reliabilityMajor fix · Import, numbering & match modal⌄

Fixed & improved

  • Added validated CSV, TSV and compatible JSON match import with a review step before data is saved.
  • Match numbers are editable; valid unused imported IDs are preserved while conflicts or missing IDs are reassigned to available numbers.
  • Bulk import can save ready rows while skipping rows that still need attention.
  • Import review close, cancel, backdrop, Escape and file-retry actions now behave reliably.
  • RR fields are optional during import and are validated only when supplied.
  • Consolidated match-entry modal fixes: Advanced Options are correctly positioned above Notes, optional fields stay grouped, and long expanded forms remain usable within the viewport.
v8.4 — Reliability & interface polishPatch · Stability & UI⌄

Fixed & improved

  • Fixed challenge-form submission paths that could reload the page unexpectedly.
  • Replaced disruptive browser alerts in normal workflows with in-app feedback.
  • Refined navigation, cards, tables, analytics panels, modal hierarchy and save/import feedback.
  • Consolidated analytics navigation so Top Maps remains inside the Analytics experience.
v8.0 — Competitive analytics overhaulMajor update · Analytics foundation⌄
  • Introduced accuracy analytics, recent HS% trends and role performance.
  • Added Top Agents and Top Maps analysis with data-driven performance metrics.
  • Added agent/map win-rate analysis and cross-analysis foundations.
  • Redesigned Match History and strengthened the dashboard information hierarchy.
